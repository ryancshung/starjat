# StarJar 2026-08-31 升級清單

本次升級聚焦在獎勵開放規則、星星安全管理、零用錢、家庭回顧與孩子成就感。正式版本已部署至 [StarJar](https://starjat.vercel.app)。

## 家庭設定與權限

- 家庭新增時區設定，既有家庭預設為 `Asia/Taipei`。
- 家庭建立者是唯一家庭管理者，可設定全家庭的零用錢兌換比例。
- 管理者可逐一決定一般家長是否具有扣星權限；一般家長預設不可扣星。
- 每位孩子可設定每月零用錢兌換上限，留空代表不限。

## 安全扣星

- 家庭管理者永遠可以扣星；一般家長必須先取得管理者授權。
- 開啟家長扣星權限時會先顯示風險警語。
- 每一次扣星都會再次顯示完整警語，不提供略過或「不再顯示」。
- 送出前會列出孩子、原因、扣除數量及扣除前後餘額。
- 扣星原因必填，且不可讓孩子餘額低於零。
- 扣星紀錄不可刪除；誤扣時只有家庭管理者可使用「補回」，並留下原始扣星與更正原因。

## 限定日期獎勵與星星保留

- 獎勵可設定為「隨時開放」、「僅週六、週日」、「僅指定日期」或「週末或指定日期」。
- 可額外限制同一天內的開始及結束時間；未填時間代表當日全天。
- 開放資格以孩子提出兌換申請的時間及家庭時區判定。
- 未開放的獎勵仍會顯示，但會鎖定並說明原因與下一次開放時間。
- 送出申請後會保留所需星星；核准時正式扣除，拒絕或撤回時釋放。
- 申請會保存當時價格、折扣與開放資格，後續修改不影響舊申請。
- 孩子可以撤回尚未核准的一般獎勵申請，撤回紀錄仍會保留。

## 零用錢與定期派發

- 「零用錢」頁整合零用錢兌換及定期發星星。
- 管理者以「幾顆星 = NT$1」設定全家庭一致的兌換比例；未設定時停用兌換。
- 孩子只能輸入正整數新台幣，送出後由家長核准；核准即完成。
- 待審及當月已核准金額都會占用孩子的自然月上限。
- 孩子可撤回尚未核准的零用錢申請，並立即釋放保留星星及額度。
- 定期派發可設定每天、每週或每月，以及家庭當地執行時間。
- 系統每 15 分鐘檢查到期排程；錯過多期時最多補最近一期。

## 每月回顧

- 新增「月報」頁，以家庭時區及自然月即時計算。
- 家長可切換家庭總覽或個別孩子；孩子只能查看自己的報表。
- 顯示月初／月底星星、獲得、獎勵、零用錢、扣星、補回、任務與新獎盃。
- 家庭總覽依成員顯示摘要，不做孩子排名或手足比較。
- 孩子版不顯示被拒絕任務名稱，只提供件數與中性鼓勵提示。
- 提供 A4 列印版，可透過瀏覽器列印或另存 PDF。

## 獎盃系統

- 新增銅星盃、銀星盃、金星盃及星耀盃四個階級。
- 系統獎盃涵蓋任務完成、累積次數、連續天數、任務群組、累積星星、首次兌換及願望達成。
- 家庭管理者可建立自訂獎盃，設定階級、解鎖方式、門檻及是否隱藏。
- 一般家長可手動頒發尚未解鎖的獎盃。
- 獎盃不附帶額外星星，解鎖後永久保留，不因扣星或任務未核准而收回。
- 由舊資料回溯取得的獎盃會標示「依既有紀錄解鎖」。
- 展示櫃支援進度顯示與系統的減少動態效果設定。

## 資料與系統可靠性

- 餘額新增「保留星星」與「可用星星」，避免多筆待審申請重複使用同一批星星。
- 後端會再次驗證角色、家庭權限、正整數、原因、餘額、日期資格及月上限。
- 核准、撤回及扣款採交易處理，避免同一申請因競態重複成功。
- Worker 排程更新為每 15 分鐘執行。
- 保留 Express API 作為備援，並與 Cloudflare Worker 維持功能一致。
