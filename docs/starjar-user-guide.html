StarJar 使用說明書

讓孩子在完成任務、實現願望的過程中累積星星
2026-08-31 更新

StarJar 是家庭專用的任務與獎勵系統。家長建立任務、核准完成情況並管理獎勵；孩子完成任務後累積星星，再用星星兌換喜歡的獎勵。

1. 開始使用、家庭設定與權限

家庭管理者

註冊家長帳號時不填邀請碼，接著建立家庭。家庭建立者是唯一家庭管理者，可以管理家庭名稱、邀請碼、成員、家庭時區、零用錢比例及家長扣星權限。

受邀家長與孩子

註冊時填入家庭邀請碼即可加入既有家庭。受邀家長可以建立任務、獎勵及審核；一般家長預設沒有扣星權限。孩子只會操作自己的任務、申請與紀錄。

邀請成員

  1. 家庭擁有者開啟「家庭」頁面。
  2. 複製家庭邀請碼並傳給對方。
  3. 對方在註冊頁選擇身分，填入邀請碼後完成註冊。
家庭邀請碼可供家長或孩子使用；孩子只會看到自己的星星與可完成／兌換的內容。

家庭設定

  • 管理者在「家庭」頁設定家庭時區；既有家庭預設為 Asia/Taipei。
  • 設定零用錢比例時，請填入「幾顆星 = NT$1」中的星星數；留空代表暫停零用錢兌換。
  • 每位孩子可個別設定每月零用錢上限；留空代表不限。
  • 管理者可逐一家長開啟扣星權限。開啟時系統會先顯示風險警語。

2. 任務管理

家長：新增與設定任務

  • 在「任務」頁按 ＋新增任務，輸入名稱、說明與完成後的星星數。
  • 可建立群組（例如：早晨、學校、家事），並將任務放入群組。
  • 可設定每日或每週重複、完成次數上限，以及核准後是否繼續保留。
  • 按「排序」後可拖曳任務或使用上下鍵調整；按「儲存排序」才會正式套用。

孩子：完成任務

  1. 開啟任務列表，使用群組標籤切換瀏覽。
  2. 按任務右側的「完成」。
  3. 等待家長在首頁／待審核項目中核准。
  4. 核准後星星會自動加入孩子帳戶。

3. 獎勵、限定日期與許願

建立獎勵

家長可新增獎勵、設定所需星星、兌換次數上限與是否在兌換後保留。孩子提出申請時會先保留所需星星；家長核准後才正式扣除，拒絕或孩子撤回時會釋放保留星星。

限定日期與時段

  • 開放規則可選「隨時開放」、「僅週六、週日」、「僅指定日期」或「週末或指定日期」。
  • 指定日期使用 YYYY-MM-DD，多個日期以逗號分隔。
  • 開始／結束時間都留空代表當日全天；若有設定，必須在該時段內提出申請。
  • 系統依家庭時區與送出申請的時間判斷。尚未開放時，獎勵卡會鎖定並提示原因與下一次開放時間。

折扣管理

  • 按「折扣管理」可對全部獎勵套用相同折扣與期間；這會覆蓋每個獎勵原有的個別折扣。
  • 按單一獎勵的「編輯」可設定或修改個別折扣、開始與到期時間。
  • 到期時間留空代表長期折扣，直到家長手動取消。折扣中的獎勵卡會顯示折扣與到期日。

孩子許願

  1. 孩子在「獎勵」頁下方的「許願區」輸入想要的獎勵。
  2. 家長查看願望後，選擇「核准」並填入所需星星數，或選擇婉拒。
  3. 核准的願望會自動加入獎勵列表。

4. 發星星、安全扣星與補回

家長發放星星

在首頁選擇孩子、輸入正整數星星與原因後送出，星星會立即加入孩子餘額並留下紀錄。

扣除星星

  1. 家庭管理者，或已被授權的一般家長，在首頁選擇「扣星」。
  2. 選擇孩子並填寫扣除數量與孩子能理解的明確原因。
  3. 閱讀每次都會出現的完整警語。
  4. 確認孩子姓名、原因、扣除數量及扣除前後餘額，再勾選確認並送出。
扣星無法刪除，也不能讓餘額低於零。若發生誤扣，家庭管理者可到「紀錄」找到該筆扣星並按「補回」，填寫更正原因。原始扣星與補回紀錄都會永久保留。

5. 零用錢與定期派發

孩子申請零用錢

  1. 開啟「零用錢」頁，確認家庭比例、可用星星與自己的每月上限。
  2. 輸入正整數新台幣金額，系統會自動換算需要的星星。
  3. 送出後等待家長核准；送審期間會保留星星與當月額度。
  4. 核准後即完成。尚未核准前，孩子可在同頁撤回申請。

同一申請會保存送出當時的兌換比例；管理者之後修改比例，不會改變舊申請。

家長設定定期派發

  1. 在「零用錢」頁按「新增定期派發」。
  2. 選擇孩子、填寫名稱與星星數量。
  3. 選擇每天、每週或每月，並設定家庭當地執行時間。
  4. 建立後可隨時暫停、重新啟用或刪除。
系統每 15 分鐘檢查到期排程。若服務錯過多期，最多補發最近一期，再推進到下一個未來時段。

每日挑戰與自訂獎勵

家長可在「任務」新增每日挑戰，選擇每日任務、適用孩子及額外獎勵。任務可以是 0 星；額外獎勵可選星星、自訂項目，或兩者都有。

  • 所有項目通過家長審核後，自動發放額外獎勵，不需再申請。
  • 自訂項目如「玩電動 30 分鐘」會出現在「獎勵 → 挑戰獎勵」，家長提供後標記已兌現，不扣星、不過期。
  • 每日任務每位孩子每天只領一次，退回可重送。同一任務可推進多組挑戰，基本星星只發一次。
  • 依家庭時區的提交日計算；隔天才審核也保留原日期及獎勵。修改每日任務或挑戰於翌日生效；當天已開始任務的孩子，新增挑戰也從翌日適用。
  • 按完成後會顯示送出中、等待家長審核、今日已完成；網路中斷時可安全重試。

6. 每月回顧

手機請按底部「更多 → 月報」。月報不是兒童專屬功能，家長也能查看。

月報分列基本任務星星、每日挑戰加碼及已獲得的自訂項目，依實際入帳／取得月份統計；自訂項目不納入星星收支。

「月報」以家庭時區及自然月即時計算。家長可查看家庭總覽或切換個別孩子；孩子只能查看自己的資料。

  • 包含月初／月底星星、獲得、獎勵、零用錢、扣星、補回、完成任務及新獎盃。
  • 家庭總覽顯示合計與每位孩子摘要，不做排名或手足比較。
  • 孩子版不顯示未核准任務名稱，只顯示件數及中性鼓勵提示。
  • 按「列印報表」可使用 A4 列印，或在瀏覽器選擇「另存為 PDF」。

7. 獎盃展示櫃

獎盃分成銅星盃、銀星盃、金星盃及星耀盃。獎盃不會額外發放星星，而且一旦解鎖便永久保留。

孩子

可查看已解鎖獎盃、尚未完成的進度及隱藏獎盃。由舊資料達成的獎盃會顯示「依既有紀錄解鎖」。

家長

一般家長可手動頒發獎盃；家庭管理者還能建立自訂獎盃，設定階級、解鎖方式、門檻與是否隱藏。

8. 星星紀錄

「紀錄」頁可查看星星獲得、兌換、扣星與補回明細，包括原因、時間及異動前後餘額。孩子可查看自己的紀錄；家長可切換查看家庭中的孩子。

9. iPhone 加入主畫面

  1. 用 Safari 開啟 StarJar 網站。
  2. 按底部「分享」按鈕。
  3. 選擇「加入主畫面」，確認名稱後按「加入」。

若已建立過舊捷徑但圖示沒有更新，請先從主畫面刪除舊捷徑，再重新加入一次。
