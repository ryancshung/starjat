StarJar 使用說明書

讓孩子在完成任務、實現願望的過程中累積星星

StarJar 是家庭專用的任務與獎勵系統。家長建立任務、核准完成情況並管理獎勵；孩子完成任務後累積星星，再用星星兌換喜歡的獎勵。

1. 開始使用與家庭邀請

建立家庭的家長

註冊家長帳號時不填邀請碼，接著建立家庭名稱。此帳號是家庭擁有者，可以管理家庭名稱、邀請碼與成員。

受邀家長與孩子

註冊時填入家庭邀請碼即可加入既有家庭。受邀家長可以建立任務、獎勵及審核，但不能管理成員名單。

邀請成員

  1. 家庭擁有者開啟「家庭」頁面。
  2. 複製家庭邀請碼並傳給對方。
  3. 對方在註冊頁選擇身分，填入邀請碼後完成註冊。
家庭邀請碼可供家長或孩子使用；孩子只會看到自己的星星與可完成／兌換的內容。

2. 任務管理

家長：新增與設定任務

  • 在「任務」頁按 ＋新增任務，輸入名稱、說明與完成後的星星數。
  • 可建立群組（例如：早晨、學校、家事），並將任務放入群組。
  • 可設定每日或每週重複、完成次數上限，以及核准後是否繼續保留。
  • 按「排序」後可拖曳任務或使用上下鍵調整；按「儲存排序」才會正式套用。

孩子：完成任務

  1. 開啟任務列表，使用群組標籤切換瀏覽。
  2. 按任務右側的「完成」。
  3. 等待家長在首頁／待審核項目中核准。
  4. 核准後星星會自動加入孩子帳戶。

3. 獎勵、折扣與許願

獎勵

家長可新增獎勵、設定所需星星、兌換次數上限與是否在兌換後保留。孩子在「獎勵」頁按「兌換」後，仍需家長核准才會扣除星星。

折扣管理

  • 按「折扣管理」可對全部獎勵套用相同折扣與期間；這會覆蓋每個獎勵原有的個別折扣。
  • 按單一獎勵的「編輯」可設定或修改個別折扣、開始與到期時間。
  • 到期時間留空代表長期折扣，直到家長手動取消。折扣中的獎勵卡會顯示折扣與到期日。

孩子許願

  1. 孩子在「獎勵」頁下方的「許願區」輸入想要的獎勵。
  2. 家長查看願望後，選擇「核准」並填入所需星星數，或選擇婉拒。
  3. 核准的願望會自動加入獎勵列表。

4. 定期派發星星

家長可從導覽列開啟「定期派發」，建立固定星星來源，例如零用星星、閱讀獎勵。

  1. 按「＋新增設定」。
  2. 選擇孩子、填寫名稱與星星數量。
  3. 選擇每天、每週或每月，並可指定開始時間。
  4. 建立後可隨時暫停、重新啟用或刪除。
系統每天約台灣時間上午 08:00 檢查一次。符合設定週期的項目會自動發放，並寫入星星紀錄。

5. 星星紀錄與列印

「紀錄」頁可查看星星獲得與支出的明細。家長在任務頁按「列印」，可開啟瀏覽器列印視窗；建議選擇 A4、直向，系統會使用雙欄任務磚塊版面以節省紙張。

6. iPhone 加入主畫面

  1. 用 Safari 開啟 StarJar 網站。
  2. 按底部「分享」按鈕。
  3. 選擇「加入主畫面」，確認名稱後按「加入」。

若已建立過舊捷徑但圖示沒有更新，請先從主畫面刪除舊捷徑，再重新加入一次。
